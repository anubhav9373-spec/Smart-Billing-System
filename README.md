# SmartBill — Frontend Foundation

This step contains only the frontend foundation requested in the SmartBill specification.

## Included
- Shared base layout
- Sidebar/navigation
- Responsive mobile navigation
- Global CSS design system
- Dashboard shell
- Products shell + demo modal/search interaction
- New Bill shell
- Sales History shell
- Invoice shell
- Analytics shell
- Settings shell
- Page-specific JavaScript placeholders

## Not included
- Flask routes
- SQLite
- Real API calls
- Authentication
- Real billing/stock logic
- Persistent data
